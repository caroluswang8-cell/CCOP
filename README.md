# Configuration-Consistent Oblique Projection (CCOP)

This repository contains the manuscript and reproducibility code for the
configuration-consistent Lagrangian pressure-projection study.  The current
article has three linked numerical cases:

1. force-free affine separation of the terminal constraint and placed
   pressure action;
2. long-time affine comparison with a same-discretization ISPH star--star
   workflow;
3. strictly nonaffine differential-vortex validation of transported geometry,
   pressure action, divergence, and the cross response.

## Repository layout

- `ccop_numerical_method.tex`: current manuscript source.
- `code/test1_affine_free_boundary.py`: affine mechanism and multistep tests.
- `code/test2_differential_vortex.py`: prescribed-map, exact-increment, and
  complete nonaffine evolution tests.
- `code/card_piola_pressure_matrixfree_jax_v12_{sph2,mls2}_three_branch_strict.py`:
  strict matched-ISPH and CCOP long-time drivers, with an optional
  terminal--terminal development control not used in the Case 2 main comparison.
- `code/constant_translation_audit.py`: constant-field and frozen-translation
  consistency audit.
- `code/test_test1_affine_free_boundary.py` and
  `code/test_test2_differential_vortex.py`: automated regression gates.
- `MANUSCRIPT_REVISION_NOTES.md`: scope reduction, terminology ledger, and
  manuscript consistency audit.
- `results/`: manuscript figures, compact tables, configuration records, and
  short reports.  Full per-iteration JSON files are regenerated by the drivers
  and are intentionally not duplicated in the source repository.

## Environment

Python 3.11 or newer is recommended.  From a PyCharm terminal in the repository
root:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

The strict long-time comparison requires JAX in actual 64-bit mode.  The
driver aborts rather than silently continuing in single precision.

## Fast validation

```powershell
.\.venv\Scripts\python.exe -m pytest code\test_test1_affine_free_boundary.py code\test_test2_differential_vortex.py -q
.\.venv\Scripts\python.exe code\test1_affine_free_boundary.py --quick
.\.venv\Scripts\python.exe code\test2_differential_vortex.py --quick --phase all --production-matrix gate
```

Full manuscript studies:

```powershell
.\.venv\Scripts\python.exe code\test1_affine_free_boundary.py
.\.venv\Scripts\python.exe code\test2_differential_vortex.py --phase all --production-matrix full
.\.venv\Scripts\python.exe code\constant_translation_audit.py
```

## Long-time matched ISPH comparison

The defaults below are `R/dx=50`, `dt=0.002`, and `T=30`.  The star--star
branch is the same-discretization ISPH workflow used by the manuscript.

```powershell
.\.venv\Scripts\python.exe -u code\card_piola_pressure_matrixfree_jax_v12_sph2_three_branch_strict.py --backend cpu --branch ccop-midpoint --output sph2_ccop_midpoint_Rdx50_dt0p002_T30.npz
.\.venv\Scripts\python.exe -u code\card_piola_pressure_matrixfree_jax_v12_sph2_three_branch_strict.py --backend cpu --branch star-star --output sph2_star_star_Rdx50_dt0p002_T30.npz
```

Replace `sph2` by `mls2` in the filename to run the MLS2 realization.  The
strict drivers use raw accepted Jacobians, complete represented residuals, a
hard geometry rebuild, and no diagonal pressure shift or pseudo-inverse.

## Reproducibility boundary

The committed tables and figures document the reported runs.  The full JSON
archives are large generated artifacts; each driver records its configuration,
complete nonlinear histories, and deterministic seed when rerun.
